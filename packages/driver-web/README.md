# @toets/driver-web

toets driver for web TV apps in Chromium, built on Playwright. Loaded by `@toets/test` for `platforms.web()` projects.

Docs (shipped in `docs/`):

- [Setup](./docs/setup.md): install, configure, where the browser page comes from
- [Options](./docs/options.md)
- [Launch payload](./docs/launch.md)
- [Keys](./docs/keys.md): default map, overrides, long press
- [Element mapping](./docs/element-mapping.md): how the DOM becomes element snapshots
- [Capabilities](./docs/capabilities.md)
- [TV traps](./docs/tv-traps.md)

Project overview: [toets](https://github.com/yusufyildirim/toets#readme).
