# @dpad-tv/protocol

The dpad in-app SDK protocol (JSON-RPC 2.0 over WebSocket, app connects to the host): message types, launch payload codec and a JSON-RPC peer (`@dpad-tv/protocol`, browser safe), the host server (`@dpad-tv/protocol/host`, Node) and the conformance suite (`@dpad-tv/protocol/conformance`, `dpad-conformance` CLI).

Docs (shipped in [`docs/`](./docs)): [spec](./docs/spec.md), [host](./docs/host.md), [conformance](./docs/conformance.md). Project overview: [dpad](../../README.md).
