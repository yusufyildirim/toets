# @toets/protocol

The toets in-app SDK protocol (JSON-RPC 2.0 over WebSocket, app connects to the host): message types, launch payload codec and a JSON-RPC peer (`@toets/protocol`, browser safe), the host server (`@toets/protocol/host`, Node) and the conformance suite (`@toets/protocol/conformance`, `toets-conformance` CLI).

Docs (shipped in `docs/`): [spec](./docs/spec.md), [host](./docs/host.md), [conformance](./docs/conformance.md). Project overview: [toets](https://github.com/yusufyildirim/toets#readme).
