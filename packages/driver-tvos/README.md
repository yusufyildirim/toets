# @toets/driver-tvos

toets driver for tvOS simulators, built on WebdriverIO and Appium XCUITest. Loaded by `@toets/test` for `platforms.tvOS()` projects.

Docs: [`docs/`](./docs/index.md) (shipped at `node_modules/@toets/driver-tvos/docs`). Project overview: [toets](https://github.com/yusufyildirim/toets#readme).

Fixture app for the driver's own integration tests: [`fixtures/tvos-app`](https://github.com/yusufyildirim/toets/tree/main/packages/driver-tvos/fixtures/tvos-app) (`pnpm build:fixture`).
