# @dpad-tv/driver-tvos

dpad driver for tvOS simulators, built on WebdriverIO and Appium XCUITest. Loaded by `@dpad-tv/test` for `platforms.tvOS()` projects.

Docs: [`docs/`](./docs/index.md) (shipped at `node_modules/@dpad-tv/driver-tvos/docs`). Project overview: [dpad](https://github.com/yusufyildirim/dpad#readme).

Fixture app for the driver's own integration tests: [`fixtures/tvos-app`](https://github.com/yusufyildirim/dpad/tree/main/packages/driver-tvos/fixtures/tvos-app) (`pnpm build:fixture`).
