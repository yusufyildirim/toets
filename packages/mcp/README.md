# @toets/mcp

toets MCP server: drive TV apps from agents with the same core code tests run (launch, remote keys, focus navigation, text snapshots, matchers) and search the toets docs. It reads the targets from your toets test config.

```sh
pnpm add -D @toets/mcp
claude mcp add --scope project toets -- npx toets-mcp
```

Docs: [setup](./docs/setup.md), [tools](./docs/tools.md), [workflow](./docs/workflow.md). Project overview: [toets](https://github.com/yusufyildirim/toets#readme).
