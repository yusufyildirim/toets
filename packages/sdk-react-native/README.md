# @dpad-tv/sdk-react-native

dpad in-app SDK adapter for React Native: react-native-tvos (Android TV, Fire TV, tvOS) and react-native-web. Inert unless the app is launched by dpad; excludable from production builds.

```ts
import { startDpad } from '@dpad-tv/sdk-react-native';
startDpad();
```

Docs (shipped in [`docs/`](./docs)): [integration](./docs/react-native.md), [focus](./docs/focus.md), [idle](./docs/idle.md), [media](./docs/media.md), [production builds](./docs/production.md), [traps](./docs/traps.md). Project overview: [dpad](../../README.md).
