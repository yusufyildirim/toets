# @toets/sdk-react-native

toets in-app SDK adapter for React Native: react-native-tvos (Android TV, Fire TV, tvOS) and react-native-web. Inert unless the app is launched by toets; excludable from production builds.

```ts
import { startToets } from '@toets/sdk-react-native';
startToets();
```

Docs (shipped in `docs/`): [integration](./docs/react-native.md), [focus](./docs/focus.md), [idle](./docs/idle.md), [media](./docs/media.md), [production builds](./docs/production.md), [traps](./docs/traps.md). Project overview: [toets](https://github.com/yusufyildirim/toets#readme).
